# Ahmed Salah — Free Interactive Portfolio

This is a static HTML/CSS/JavaScript portfolio starter designed around the requested interaction:

Home → click Motion & Reels → six reel thumbnails appear in an overlay on the SAME page → click a reel → video lightbox → arrows to move between reels.

## Add your real videos
1. Create: `assets/videos/`
2. Put your MP4 files there using these names:
   - hoven.mp4
   - lency.mp4
   - add-relish.mp4
   - faylasofah.mp4
   - isis.mp4
   - bae-agency.mp4
3. Open `script.js` if you want to change filenames.

## Replace thumbnails
Replace:
- assets/reel-01.svg
- assets/reel-02.svg
- assets/reel-03.svg
- assets/reel-04.svg
- assets/reel-05.svg
- assets/reel-06.svg

Keep the same filenames, or update the HTML.

## Publish for free
GitHub Pages can host static HTML/CSS/JavaScript files for free in a public repository.
Create a repository named `YOURUSERNAME.github.io`, upload these files, then enable Pages from Settings → Pages → Deploy from a branch.

Your live address will be:
https://YOURUSERNAME.github.io/

No monthly website-builder subscription is required.
